# High Speed Net Stack

A collection of assignments, laboratory exercises, experiments, and implementations developed as part of the **High Performance TCP/IP Protocol Stack** course.

The repository focuses on understanding how networking works inside the Linux operating system, exploring TCP/IP stack internals, and studying techniques for analyzing and improving system and network performance.

## Topics

- **Linux Kernel Internals:** Exploring kernel mechanisms involved in networking and system operations.
- **TCP/IP Stack:** Understanding TCP/IP protocols and their implementation in the Linux kernel.
- **Performance Analysis:** Measuring and investigating system and network performance.
- **Kernel Tracing and Profiling:** Observing kernel events, function calls, and execution behavior.
- **Memory and System Calls:** Investigating memory management, system calls, and their interactions with the kernel.

## Environment

The primary environment for the course is **Ubuntu 22.04**, with the required development and tracing tools installed locally.

## Purpose

This repository serves as a record of my coursework and practical exploration of high-performance networking, Linux kernel behavior, and performance engineering.
